How do I install it?

Android: tap Install Daranor when shown, or open Chrome’s menu and choose Install app / Add to Home screen.

iPhone or iPad: open this page in Safari, tap Share, choose Add to Home Screen, turn on Open as Web App, then tap Add.

Open the installed game while online once, then finish the campaign download above before going offline.
