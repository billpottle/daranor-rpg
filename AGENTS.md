# Repository Instructions

- Never use SVG for generated or replacement visual assets unless the user explicitly instructs it.
- Prefer image generation for new game imagery, including item art, character art, armor, weapons, locations, and promotional art.
- Treat `packages/engine/` and `packages/ui/` as the canonical runtime and interface. Do not fork them into a campaign.
- Keep campaign story, maps, encounters, balance, and game-specific assets under `games/<campaign>/`.
- Put byte-identical runtime media used by both campaigns under `shared/assets/`; the build composes self-contained campaign outputs.
- Run `npm run validate` after changing game data or assets, and `npm test` after changing shared runtime behavior.
- Do not commit `dist/`; it is generated by `npm run build`.
